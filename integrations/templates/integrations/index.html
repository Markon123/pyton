Как подключить API

Сессия браузера с CSRF либо JWT через /api/v1/auth/login/. Партнёр передаёт заголовок Authorization: Partner токен.

Чтение календаря: GET /api/v1/competitions/. Импорт: POST /api/v1/competitions/ID/results/import/ с JSON {"results":[{"application":1,"place":1,"score":100}]}.

Описание всех процессов и примеры — в docs/api.md репозитория.
