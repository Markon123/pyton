# ОренКод · единая цифровая платформа ФСП

Платформа спортивного программирования Оренбургской области: соревнования, заявки, результаты, реестр, разряды и судейские категории, рейтинг, сборная, отчёты и дополнительные модули. Поддерживаются все шесть дисциплин.

**[Скачать проект ZIP](https://github.com/Markon123/pyton/archive/refs/heads/main.zip)**. GitHub хранит исходники; публичный сайт размещается отдельно.

## Запуск на Windows

1. Установите [Python 3.12+](https://www.python.org/downloads/windows/) с параметром **Add Python to PATH**.
2. Скачайте ZIP и полностью распакуйте: правая кнопка → **«Извлечь всё»**.
3. Откройте распакованную папку и запустите **start.bat**. Первая установка требует интернет.
4. Дождитесь открытия браузера. Окно запуска оставьте открытым.
5. Откройте **.local/first-access.txt** в папке проекта: там логин министерства (по умолчанию **ministry**) и случайный временный пароль вашей установки.
6. При первом входе задайте собственный пароль и подтвердите согласие. Временный пароль после смены перестаёт действовать.

macOS/Linux: **bash start.sh**. Лаунчер подготавливает окружение, миграции, справочники и единственный главный аккаунт министерства. Рабочая база — .local/platform.sqlite3. Вымышленные участники, соревнования и готовые результаты не создаются. Повторный запуск пароль не сбрасывает.

Если администратор задал FSP_MINISTRY_PASSWORD в защищённых настройках, файл первоначального доступа не создаётся. Пароли и содержимое .local не публикуйте в Git или чате. [Подробности запуска](docs/local-launch.md).

## Кто создаёт аккаунты

| Аккаунт | Как появляется | Возможности |
| --- | --- | --- |
| Министерство | Единственный главный аккаунт создаётся при установке и хранится в БД | Создание, отключение и восстановление доступа аккаунтов федераций; разрешённые сводки |
| Федерация | Только через министерство, раздел «Аккаунты федераций» | Соревнования, модерация, реестр, результаты, квалификации, рейтинг, сборная, документы |
| Спортсмен | Самостоятельная регистрация | Профиль, заявки, результаты, разряд, подготовка и справки |
| Тренер | Самостоятельная регистрация | Подтверждённые спортсмены, заявки и квалификации по дисциплине связи, группы |
| Судья | Самостоятельная регистрация | Категория, назначения и документы судейства |

Спортсмен, тренер и судья могут совмещать роли и переключаться без повторного входа. Министерство и федерация отсутствуют в самостоятельной регистрации. Федерация не может выдавать служебные роли себе или другим. Владелец каждого нового служебного аккаунта при первом входе меняет временный пароль. Пароли в БД хранятся в виде хэшей.

## Сервер, почта и проверки

Для сервера предусмотрены PostgreSQL, Docker Compose, Gunicorn, планировщик и HTTPS через Caddy. [Размещение и резервные копии](docs/deployment.md). При первой установке выполняются migrate, prepare_project и bootstrap_ministry; Docker entrypoint делает это автоматически. Произвольный .env обычный Python-запуск не читает; Compose использует --env-file.

SMTP поддерживает STARTTLS и SSL. До подключения почтового сервиса письма сохраняются локально; это не доставка во внешний ящик. [Настройка почты и проверка получения](docs/mail.md). Публичная проверка QR требует действительного HTTPS-адреса PUBLIC_BASE_URL.

Проверки из активированного окружения:

    python manage.py check
    python manage.py makemigrations --check --dry-run
    python manage.py test

Тесты используют отдельную БД и фиктивные данные. [GitHub Actions](https://github.com/Markon123/pyton/actions) проверяет Windows/Ubuntu и PostgreSQL. Команды seed_* предназначены для изолированных стендов разработчика и при обычной установке не вызываются.

[Архитектура](docs/architecture.md), [API](docs/api.md), [сценарии проверки](docs/acceptance.md), [матрица требований](docs/compliance.md), [исходный аудит](docs/tz-audit-2026-10-28.md), [первый чекпоинт](docs/checkpoint-1.md), [личные данные](docs/privacy.md).

Форматы XLSX/DOCX/PDF реализованы. Образцов утверждённых бланков в присланном ТЗ нет, поэтому точное совпадение с официальной формой не подтверждено. Шапки и подписанты настраиваются. Критерии нормативов и премий необходимо заполнять по действующим источникам; программа не присваивает государственный разряд автоматически.

## Обновление с прежнего учебного запуска

Новая локальная установка использует .local/platform.sqlite3. Прежняя .local/db.sqlite3 не подключается автоматически и не удаляется. Если в ней есть нужные данные, сначала сохраните копию и выполните контролируемый перенос. Существующий PostgreSQL не очищается: применяются миграции и первоначальная настройка министерства. Старые start-demo.bat/start-demo.sh запускают ту же рабочую платформу без вымышленных данных.
