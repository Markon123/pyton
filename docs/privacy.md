# Собственные данные и обращения

Авторизованный пользователь открывает «Мои данные» из профиля. JSON-выгрузка содержит данные текущего аккаунта: профиль, согласия, свои заявки/результаты/квалификации, связи, подготовку и связанные записи. Выбрать чужого пользователя параметром нельзя. Пароли, хэши, сессии, ключи и токены не экспортируются.

Пользователь подаёт обращение об удалении и видит его состояние и историю. Федерация рассматривает обращение с мотивированным ответом. Другой спортсмен или тренер не получает чужое обращение. Повторная отправка не создаёт несколько открытых обращений.

«Удаление согласовано» означает решение по обращению, а не уничтожение исторических документов. Фактическое удаление/обезличивание выполняется с учётом согласованной политики хранения. Программа не выдаёт согласование за исполненное удаление.

Проверки: python manage.py test privacy_requests.
