# Экспорт документов

`federation.documents.build_document()` формирует настоящие файлы XLSX, DOCX и PDF из строк, которые передаёт представление. Проверка прав и фильтрация данных выполняются до вызова генератора. Ответы помечены `private, no-store`.

Это **демонстрационные табличные формы**, а не утверждённые формы федерации или министерства: исходное ТЗ не содержит приложений с официальными шаблонами. На каждом документе есть отметка «Демонстрационный документ · вымышленные данные». Проект приказа требует проверки и оформления уполномоченным сотрудником.

Для внедрения необходимо получить утверждённые шаблоны, согласовать поля и подписантов. Затем следует заменить соответствующий генератор или подключить DOCX-шаблон, сохранив существующие проверки доступа в представлениях. Не удаляйте пометку о демонстрационных данных, пока база используется для демонстрации.

- XLSX: типизированные числовые значения, закреплённые заголовки, автофильтр и защита текстовых ячеек от формульной инъекции.
- DOCX: редактируемая таблица с повтором заголовка; для широких таблиц используется альбомная ориентация.
- PDF: встроенный кириллический шрифт DejaVu Sans, повтор заголовков и разбиение длинных ячеек по страницам.

Шрифты DejaVu Sans и DejaVu Sans Bold находятся в `federation/assets/fonts/`; их лицензия сохранена рядом в `LICENSE.txt`. Для экспорта не нужен доступ к CDN или внешнему сервису.

Проверка: `python manage.py test federation.test_documents` в активированном окружении проекта.
