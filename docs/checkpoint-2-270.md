# Второй чекпоинт — видео на 4 минуты 30 секунд

**[Скачать MP4 с русской озвучкой](https://github.com/Markon123/pyton/raw/refs/heads/main/docs/checkpoint-2-270.mp4)**

Длительность — ровно 270 секунд. Источник приложения — версия второго чекпоинта, commit [953b71b](https://github.com/Markon123/pyton/tree/953b71b3f647cd47d03dae2e12e758b9a0c6d09f).

Основной цикл соревнования взят из [исходного видео сдачи](checkpoint-2.mp4), побайтно проверенного по Git. Дополнительные сцены записаны на отдельной копии того же исходного кода; файлы приложения в историческом checkout не изменялись. Позднейшие изменения аккаунтов, интерфейса и функциональности в эту запись не включены.

Это новый сокращённый монтаж по исторической версии, а не утверждение, что именно этот файл был отправлен на 42-м часу. При монтаже сокращены паузы, изменён темп отдельных фрагментов и добавлены русская озвучка, титры и главы. Все участники и данные вымышлены.

Подготовка и запись вынесены в scripts/prepare_checkpoint2_270.py и scripts/record_checkpoint2_270.cjs; сборка — scripts/package_checkpoint2_270.py. Изолированные база, ключи, файлы и исходные записи находятся в игнорируемом каталоге .local/checkpoint2-270. Рабочая база платформы не используется.

Для воспроизведения создайте рядом с основным репозиторием отдельный checkout: git worktree add --detach ../pyton-checkpoint2-270 953b71b. Скрипт подготовки ожидает именно эту папку и проверяет commit и отсутствие изменений исходников. Параметры и защитные проверки описаны в --help скриптов. План JSON и 17 фрагментов озвучки задают монтаж ровно на 270 секунд. Обычный запуск веб-приложения не требует средств записи или TTS.
