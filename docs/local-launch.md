# Открыть демоверсию на своём компьютере

1. Полностью распакуйте ZIP в обычную папку. Не запускайте файлы прямо внутри архива.
2. Установите Python 3.12 или новее с [python.org](https://www.python.org/downloads/). В установщике Windows включите **Add Python to PATH**.
3. **Windows:** дважды щёлкните `start-demo.bat`. **macOS/Linux:** откройте терминал в распакованной папке и выполните `bash start-demo.sh`.
4. При первом запуске дождитесь установки пакетов — для этого нужен интернет. Затем браузер автоматически откроет приложение.
5. Войдите: логин `federation`, пароль `FspDemo2026!`. Во время работы оставьте окно запуска открытым. Для остановки нажмите **Ctrl+C**.

Лаунчер сам создаёт окружение `.venv`, устанавливает закреплённые зависимости, применяет миграции и добавляет вымышленные демоданные. Повторный запуск сохраняет ваши записи. Это запуск на вашем компьютере: публичный адрес и хостинг не создаются.

## Если не заработало

- **Архив не скачивается:** сообщите, что именно происходит при нажатии на ссылку, и откуда открываете чат — браузер или мобильное приложение.
- **Python не найден:** завершите установку Python, затем откройте новое окно запуска. После установки может потребоваться перезапуск терминала.
- **На Linux нет `venv`:** установите пакет виртуальных окружений, соответствующий версии Python, через пакетный менеджер системы.
- **Порт 8000 занят:** возможно, приложение уже запущено в другом окне. Не запускайте второй экземпляр на том же порту. Для другого порта задайте `FSP_PORT`: в Windows `set FSP_PORT=8001`, затем `start-demo.bat`; в macOS/Linux `FSP_PORT=8001 bash start-demo.sh`.
- **Установка пакетов завершилась ошибкой:** проверьте интернет и скопируйте последние строки ошибки. Проверка TLS при установке остаётся включённой.
- **Окно закрылось или появилась другая ошибка:** журнал находится в `.local/launcher.log`. Скопируйте последние строки в чат, не присылайте пароли и значения переменных окружения.

Для технической проверки без открытия браузера: `python scripts/launch_demo.py --check-only`. Флаг `--no-browser` запускает сервер без автоматического открытия окна браузера. Windows-лаунчер подготовлен для стандартных `py`/`python`; нативная проверка на Windows в облачной Linux-среде не выполнялась.
