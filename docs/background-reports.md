# Фоновые отчёты

В разделе `/reporting/` федерация выбирает документ и формат XLSX/DOCX/PDF. Доступны:

- численность занимающихся с периодом, организацией, дисциплиной, возрастом и муниципалитетом;
- протокол соревнования;
- история выступлений спортсмена;
- состав сборной и проект приказа;
- состав судейской коллегии;
- история работы судьи.

В списках источников показаны названия соревнований с датами, имена спортсменов/судей и названия сборных. После отправки формы HTTP-запрос возвращает страницу задачи, не ожидая создания файла. Пользователь может продолжить работу и скачать результат позже. Планировщик `run_scheduler` вызывает `process_reports`; обработчик также запускается командой `python manage.py process_reports`.

Ссылки из других разделов могут заранее выбрать источник: `/reporting/?kind=protocol&object_id=42&fmt=pdf`. Допустимые виды: `census`, `protocol`, `athlete`, `team`, `judging-panel`, `judging-history`. Произвольные виды, пути и параметры не принимаются. Существующие задачи численности совместимы с прежним форматом параметров.

Предварительный протокол доступен только федерации после закрытия регистрации, рассмотрения всех заявок и сохранения всех одобренных результатов. Он не публикует соревнование. Рабочая задача повторно проверяет доступность источника: если соревнование вновь открыто или данные удалены, файл не выдаётся как успешно сформированный.

Задачи и файлы доступны только создавшему их пользователю в активной роли федерации. До формирования также проверяются текущая роль и активность аккаунта; отозванные права не сохраняются в поставленной ранее задаче. Документы используют те же представления и проверки прав, что и обычная выгрузка, без сетевого запроса и без доступа к чужой задаче.

Имена файлов создаются системой. Пятиминутная аренда и атомарное назначение защищают от одновременной обработки; после истечения аренды незавершённая задача может быть перехвачена другим обработчиком. Каждая аренда пишет отдельный файл. Публикуется только файл текущего обработчика; старый обработчик не может перезаписать его. Ошибки показывают общее сообщение без внутренних путей или значений исключения. Состояние своей задачи доступно также в JSON с заголовком `Accept: application/json`.

Данные берутся на момент обработки задачи. При изменении источника новая выгрузка может отличаться от прежней; готовый файл остаётся снимком на момент формирования. Для работы нескольких процессов каталог `.local/reports` должен находиться в общем постоянном томе приложения и планировщика.
