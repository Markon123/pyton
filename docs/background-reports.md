# Фоновые отчёты

В разделе `/reporting/` федерация выбирает период и фильтры численности, формат XLSX/DOCX/PDF и ставит задачу в очередь. Планировщик `run_scheduler` вызывает `process_reports`; команда также запускается вручную. HTTP-запрос не ожидает формирования документа. Состояние задачи доступно в интерфейсе и JSON при заголовке `Accept: application/json`.

Задачи и файлы доступны только создавшему их пользователю в активной роли федерации. Имена файлов создаются системой; произвольные пути не принимаются. Рабочая аренда и атомарное назначение защищают от одновременной обработки; после истечения аренды незавершённая задача может быть перехвачена другим обработчиком. Публикуется только файл текущего обработчика. Ошибки не раскрывают внутренние параметры.
