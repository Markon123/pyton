# Спортивная подготовка: Д3 и Д4

Раздел `/training/` объединяет программы организаций, группы, историю зачислений, журнал занятий, нормативы и промежуточную аттестацию.

## Проверка через интерфейс

1. Федерацией откройте **Спортивная подготовка**, добавьте программу: организация, дисциплина, этап, реквизиты лицензии. Создайте группу с тренером по той же дисциплине.
2. Зачислите спортсмена, указав дату, муниципалитет и пол для нормативов. У спортсмена должна быть дисциплина группы. Тренер может управлять своей группой и только спортсменами с подтверждённой тренерской связью по дисциплине.
3. В карточке группы добавьте занятие. Для онлайн-формата обязательна ссылка на запись или лог; для очного — достаточно записи в журнале. На странице занятия отметьте присутствовавших. Зачисление проверяется именно на дату занятия. Ошибку в теме, формате или ссылке можно исправить; дату занятия нельзя перенести за пределы зачисления уже отмеченного спортсмена.
4. В справочнике **Нормативы и аттестация** федерация задаёт условия по дисциплине, этапу и полу: «не менее» или «не более» порога, единицу измерения, обязательность, источник. Флаг демо явно отделяет условные значения от проверенных нормативов.
5. Тренер или федерация записывает сдачу из карточки группы. Результат автоматически сравнивается с порогом; история сохраняет порог и направление сравнения на момент записи.
6. Карточка группы показывает готовность спортсмена. Учитывается последний результат каждого действующего обязательного норматива за 365 дней, применимого к полу, дисциплине и этапу. При отсутствии обязательных нормативов готовность не подтверждается. Неуказанный пол также не позволяет обойти обязательные нормативы по полу: уточните данные зачисления и внесите соответствующие результаты.
7. Откройте **Аттестация и перевод**, выберите группу непосредственно следующего этапа той же дисциплины. Проверка выполняется повторно на сервере. Старое зачисление закрывается днём перед переводом, новое начинается в дату перевода. Основание аттестации сохраняется отдельной записью с результатами и порогами.

Спортсмен видит только собственные зачисления, результаты, посещаемость и историю. Чужой тренер и неподтверждённый спортсмен не получают доступ к карточке группы. Министерству доступен только перечень групп без персонального журнала.

## Данные и отчёты

`Enrollment` хранит включительные `start_date`–`end_date`, муниципалитет и пол на момент зачисления. Организация, дисциплина и этап связаны с группой: после появления истории их нельзя переписать; создаётся новая группа и оформляется перевод. По одной дисциплине пересекающиеся интервалы одного спортсмена запрещены; разные дисциплины разрешены.

`training.services.participation_rows(start, end, discipline=None, organization=None, age_min=None, age_max=None, municipality=None)` возвращает исторические факты по году, спортсмену, организации и дисциплине. Повторные зачисления не дублируют такую комбинацию. Возраст в годовом отчёте рассчитывается на 31 декабря. Для общерегионального итога потребитель считает уникальные `athlete_id` по году, даже если спортсмен занимается несколькими дисциплинами. Текущие поля профиля используются как резервный источник только для спортсменов без истории зачислений.

## Демоданные и команды

```bash
python manage.py migrate
python manage.py seed_demo
python manage.py seed_training
python manage.py test training
```

`seed_training` повторяемо добавляет программы по шести дисциплинам, начальные группы и группы следующего этапа, зачисления, занятия, посещаемость и успешные результаты. Существующие пользовательские интервалы и результаты не перезаписываются.

**Пороги демо условные.** Они показывают работу механики; это не значения приказа Минспорта № 445. Для использования утверждённых нормативов сотрудник федерации вносит проверенные значения и источник в справочник. Проверку действующей редакции нормативных документов выполняет ответственный сотрудник.
