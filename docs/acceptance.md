# Проверка сквозных сценариев MVP

Все аккаунты и сведения в демонстрации вымышлены. Эти проверки подтверждают работу приложения; они не подтверждают соответствие официальным формам документов или законодательству о персональных данных.

Автоматические интеграционные проверки находятся в `federation/tests.py`; проверки файлов XLSX/DOCX/PDF — в `federation/test_documents.py`.

```bash
python manage.py test
```

## Соревнование → результат → разряд

1. В роли федерации создайте соревнование с дисциплиной, возрастными ограничениями, датами и демонстрационным положением PDF/DOCX. Откройте приём заявок.
2. Войдите спортсменом с подходящим возрастом и дисциплиной. Подайте заявку.
3. Войдите федерацией. Одобрите заявку, закройте приём, внесите место и баллы. Опубликуйте протокол.
4. У спортсмена проверьте историю выступлений и скачивание протокола.
5. Подайте заявку на разряд с конкретным результатом опубликованного соревнования. Если у спортсмена есть действующий тренер по дисциплине, заявку подаёт тренер.
6. Федерацией укажите дату присвоения, срок действия и номер демонстрационного приказа. Проверьте разряд в карточке спортсмена и уведомление в его кабинете.

Автотест дополнительно проверяет невозможность записи результата без одобренной заявки, публикации неполного протокола, изменения опубликованного результата, использования чужого результата при запросе разряда и присвоения без корректных дат/приказа.

## Тренер → подтверждение связи → заявка

Тренер запрашивает привязку к спортсмену по дисциплине. Пока спортсмен не подтвердил связь, тренер не может подать за него заявку. После подтверждения тренер подаёт заявку и отслеживает её статус. Связь по одной дисциплине не даёт полномочий по другим.

## Рейтинг → состав сборной

Откройте рейтинг за сезон и дисциплину. Сверьте баллы с опубликованными результатами. Два призовых места на разных соревнованиях дают коэффициент 1,2 к сумме баллов. Действующая дисквалификация исключает спортсмена из рейтинга. Федерация выбирает спортсменов из отфильтрованного рейтинга, сохраняет сборную и выгружает проект документа. Нельзя добавить отсутствующего в рейтинге спортсмена подменой запроса.

## Динамика численности

Сравните показатели за два года и скачайте XLSX. В расчёте участвуют интервалы `start_year`–`end_year`; фильтры организаций и дисциплин применяются к текущим сведениям реестра. Это не журнал исторических переводов между организациями.

## Права доступа и согласия

Проверьте регистрацию с согласием на обработку ПДн и дополнительные обязательные сведения/согласие представителя для несовершеннолетнего. Через регистрацию нельзя получить роль федерации. Переключение роли меняет доступные полномочия: аккаунт с ролью федерации, переключённый в спортсмена, не может выполнять административные действия. Нельзя просматривать чужую приватную карточку или экспортировать её данные без предусмотренной связи. Изменяющие запросы защищены CSRF.

## Письма и напоминания

В локальной конфигурации письма сохраняются в `.local/mail/`: это проверяемый почтовый транспорт для разработки, а не реальная внешняя доставка. Для доставки получателям настройте SMTP и проверьте отправку с предоставленными сервером реквизитами. Команда `python manage.py send_reminders` формирует напоминания; для регулярной работы её следует запускать планировщиком.
